# ParkPulse Site

Public landing page for [ParkPulse](https://useparkpulse.com) 2.1 — a compact, park-first ride-wait dashboard with live status context, Worth a Look, crowd pressure trends, favorites and ride watches across Walt Disney World and Disneyland Resort (six parks, 101 tracked attractions).

- Landing page: https://useparkpulse.com
- ParkPulse app: https://app.useparkpulse.com
- App repository: https://github.com/JamestheGreat1/park-pulse-web

This repository is intentionally static so it can be hosted directly on GitHub Pages.

The phone preview uses illustrative wait data, not a real-time feed. It reflects the ParkPulse 2.1 overview layout without making live availability claims.
